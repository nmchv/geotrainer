# GeoTrainer как приложение (PWA)

В репозитории уже есть `manifest.webmanifest`, `sw.js`, `pwa.js` и иконки. Страница подключает манифест и iOS-метаданные в `<head>`, а `pwa.js` должен подключаться **после** основного inline-скрипта, перед `</body>`. Не вставляйте HTML-теги внутрь `<style>` или JavaScript-блока.

## Офлайн-тесты и карты

1. Откройте сайт по HTTPS и дождитесь первой загрузки.
2. Нажмите **«Скачать веб-приложение»** рядом с кнопкой **«Открыть глобус»**.
3. Выберите класс и нажмите **«Скачать тесты и карты»**. Пакет включает тесты, подходящие географические карты и локальные файлы глобуса. Статус загрузки и наличие готового пакета показываются в окне.
4. После загрузки пакет открывается без сети. Результаты вошедшего пользователя сохраняются локально и отправляются в Supabase, когда соединение возвращается и приложение снова активно.

На главной странице быстрые тесты, полные тесты и изучение карты свернуты в три отдельные группы. Нажмите на группу, чтобы открыть её содержимое. Порядок классов задаётся в разделе администратора кнопками со стрелками и включается в экспортируемый `tests.json`.

Базовая оболочка и файл тестов кэшируются service worker автоматически; карта конкретного класса загружается по запросу. Изменения оболочки или логики офлайн-режима требуют синхронно поднять версию shell-кэша в `sw.js` и префикс `CLASS_CACHE_PREFIX` в `sw.js` и `offlineClassCacheName()` в `index.html`, чтобы установленные приложения получили актуальную версию. При смене префикса старые пакеты удаляются, и их нужно скачать повторно. Изменение `tests.json` само создаёт новый ключ пакета.

Спутниковые тайлы глобуса загружаются с ArcGIS и требуют интернета. Векторные карты тестов и локальные данные глобуса сохраняются на устройстве.

## Установка на устройство

Установка не может запускаться сайтом без подтверждения пользователя. В окне загрузки есть кнопка установки: поддерживаемые браузеры покажут системное подтверждение; в остальных появится инструкция.

- **iPhone / iPad (Safari):** «Поделиться» → «На экран Домой» → «Добавить». Установка выполняется вручную в Safari.
- **Mac (Safari 17+):** меню «Файл» → «Добавить в Dock…».
- **Chrome / Edge на компьютере:** кнопка установки в адресной строке или меню браузера → «Установить приложение».

Для service worker нужен HTTPS (localhost подходит для разработки). Проверить публикацию можно по адресам `/manifest.webmanifest` и `/sw.js`.

## Push-уведомления

`sw.js` принимает push, а `pwa.js` умеет создавать подписку. GitHub Pages не может отправлять уведомления, поэтому нужен backend или сервис, который хранит подписки и отправляет push с закрытым VAPID-ключом. На iPhone push поддерживается в iOS 16.4+ только для сайта, добавленного на экран Домой; разрешение запрашивается по нажатию кнопки.

Публичный VAPID-ключ передаётся в `enablePush(...)`, приватный ключ хранится только на сервере. Ключи можно создать командой `npx web-push generate-vapid-keys`. Например, обработчик кнопки получает подписку так:

```html
<button id="push-btn">Включить уведомления</button>
<script>
  document.getElementById('push-btn').addEventListener('click', async () => {
    try {
      const sub = await enablePush('ВАШ_ПУБЛИЧНЫЙ_VAPID_КЛЮЧ');
      // Передайте sub на свой сервер для сохранения подписки.
      await fetch('/api/push-subscriptions', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify(sub)
      });
    } catch (e) { alert(e.message); }
  });
</script>
```

Адрес `/api/push-subscriptions` — пример; его нужно заменить endpoint-ом вашего backend. Формат push-сообщения:
`{ "title": "Заголовок", "body": "Текст", "url": "/" }`
